Анализ предметной области

Тема: Менеджер контактов

1. Описание предметной области

Менеджер контактов — это программа, предназначенная для хранения и управления контактной информацией пользователей.

В повседневной жизни люди сохраняют большое количество телефонных номеров. Поэтому возникает необходимость в удобном приложении, позволяющем быстро находить, добавлять и изменять контакты.

2. Цель проекта

Разработать простой веб-сайт для хранения контактов с возможностью добавления, редактирования, удаления, поиска и группировки.

3. Целевая аудитория

Приложение предназначено для студентов и обычных пользователей, которым необходимо хранить контактную информацию.

4. Анализ существующих аналогов

Были рассмотрены три приложения:

1. Google Contacts — позволяет сохранять контакты и синхронизировать их между устройствами.
2. Apple Contacts — стандартное приложение для хранения телефонных номеров.
3. Microsoft Outlook — позволяет управлять контактами вместе с электронной почтой.

В отличие от перечисленных программ, разработанный проект имеет более простой интерфейс и не требует регистрации.

5. Основные функции проекта

* Добавление нового контакта.
* Редактирование информации.
* Удаление контактов.
* Поиск по имени.
* Разделение контактов по группам.
* Сохранение информации в браузере.

6. Используемые технологии

HTML — создание структуры сайта.

CSS — оформление интерфейса.

JavaScript — реализация функций программы.

LocalStorage — хранение контактов в браузере.

7. Заключение

В результате анализа предметной области была определена необходимость создания простого менеджера контактов.

Разработанное приложение позволяет удобно управлять контактной информацией без использования дополнительных программ.
