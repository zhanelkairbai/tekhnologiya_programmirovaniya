# Менеджер контактов

СРО №1

Дисциплина: технология программирования.

Выполнила: Кайрбай Жанель

Группа: ИС 25-21

## Цель проекта

Создать простой сайт для хранения и управления контактами.

## Возможности

1. Добавление контактов.
2. Удаление контактов.
3. Редактирование контактов.
4. Поиск по имени.
5. Разделение контактов по группам.
6. Сохранение данных в браузере.

## Использованные технологии

- HTML
- CSS
- JavaScript

## Структура проекта

index.html — структура сайта.

style.css — оформление.

script.js — функции программы.

## Запуск

Открыть сайт через GitHub Pages.
